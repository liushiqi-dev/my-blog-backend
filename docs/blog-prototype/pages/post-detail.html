Spring Boot 3.x 整合 Spring Security 实现 JWT 认证

张三 2026-08-10 1,234 阅读

在现代 Web 应用开发中，身份认证是保障系统安全的第一道防线。JWT（JSON Web Token）由于其无状态、可扩展的特性，成为前后端分离项目中的主流认证方案。

一、项目依赖

首先，在 pom.xml 中添加 Spring Security 和 JWT 相关依赖。这里使用 jjwt 库来生成和解析 Token。

<dependency>
  <groupId>org.springframework.boot</groupId>
  <artifactId>spring-boot-starter-security</artifactId>
</dependency>

二、Security 配置

通过 SecurityFilterChain 配置放行登录接口，其他请求需要携带有效的 JWT Token 才能访问。

三、登录接口

用户登录成功后，服务端生成 JWT 并返回给前端。前端将 Token 存储在本地，并在后续请求的 Authorization 头中携带。

通过以上步骤，即可完成一个基础的 JWT 认证流程。后续可以进一步扩展刷新令牌、权限控制等功能。
