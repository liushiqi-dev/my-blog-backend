## 1. 项目概述

Blog 是一个个人博客系统。**管理员（博主）** 发布和管理内容；**访客**（无论是否登录）均可浏览文章和分类。

MVP 阶段，登录与未登录用户的可见内容完全一致。注册和登录功能本期交付，为后续点赞、评论等需身份的功能预留入口。

---

## 2. 角色定义

| 角色 | 标识 | MVP 权限范围 | 说明 |
|------|------|-------------|------|
| 管理员 | `ROLE_ADMIN` | 管理文章、管理分类 | 博主本人。系统预设，不可自行注册 |
| 已登录用户 | `ROLE_USER` | **等同于未登录访客** | 通过注册获得。本期只能浏览，后续开放点赞、评论等 |
| 未登录访客 | 无角色 | 浏览文章、浏览分类 | 所有未登录的访问者 |

**关键规则：MVP 阶段，ROLE_USER 与未登录访客的可见内容和可操作范围完全一致。注册/登录功能本期仅做身份通道搭建。**

**管理员账号通过数据库初始化脚本预设。普通用户通过注册接口自行注册，角色默认为 USER。**

## 3. 功能需求

### 3.1 用户认证

---

#### FR-AUTH-01 用户注册

| 属性 | 内容 |
|------|------|
| 优先级 | P0 |
| 触发者 | 任意未登录用户 |
| 前置条件 | 无 |

**描述**

用户填写用户名、密码和邮箱完成注册。注册成功后自动获得 `ROLE_USER` 角色。

**输入**

| 字段 | 规则 |
|------|------|
| 用户名 | 必填；3-20 字符；字母/数字/下划线；不可与已有用户名重复 |
| 密码 | 必填；6-32 字符 |
| 邮箱 | 必填；须符合标准邮箱格式；不可与已有邮箱重复 |

**验收标准**

| 编号 | 场景 | 预期 |
|------|------|------|
| AC-01 | 用户名、密码、邮箱均合法且不重复 | 注册成功，角色为 USER |
| AC-02 | 用户名不足 3 字符或超 20 字符 | 失败，提示「用户名为 3-20 字符」 |
| AC-03 | 用户名包含非法字符 | 失败，提示「用户名仅支持字母、数字和下划线」 |
| AC-04 | 用户名已存在 | 失败，提示「用户名已被占用」 |
| AC-05 | 密码不足6位/超过32位 | 失败，提示「密码为6-32位」 |
| AC-06 | 用户名为空 | 失败，提示「用户名不能为空」 |
| AC-07 | 密码为空 | 失败，提示「密码不能为空」 |
| AC-08 | 邮箱格式不合法 | 失败，提示「邮箱格式不正确」 |
| AC-09 | 邮箱已存在 | 失败，提示「邮箱已被注册」 |

**业务规则**

- BR-01：密码使用 BCrypt 加密存储，不存储明文。
- BR-02：用户名全局唯一（包括管理员预设账号）。
- BR-03：注册成功后自动登录。
- BR-04：邮箱全局唯一，不可重复。

#### FR-AUTH-02 用户登录

| 属性 | 内容 |
|------|------|
| 优先级 | P0 |
| 触发者 | 任意未登录用户（含管理员和普通用户） |
| 前置条件 | 账号已存在（管理员预设 或 用户已注册） |

**描述**

用户使用用户名和密码登录系统。登录成功后返回 JWT Token，后续请求携带此 Token 以识别身份。**管理员和普通用户共用同一个登录接口。**

**输入**

| 字段 | 规则 |
|------|------|
| 用户名 | 必填 |
| 密码 | 必填 |

**返回内容（data 字段）**

| 字段 | 说明 |
|------|------|
| token | JWT 令牌 |
| username | 用户名 |
| role | 角色：ADMIN 或 USER |

**验收标准**

| 编号 | 场景 | 预期 |
|------|------|------|
| AC-01 | 管理员用户名和密码匹配 | 登录成功，返回 Token，role=ADMIN |
| AC-02 | 普通用户用户名和密码匹配 | 登录成功，返回 Token，role=USER |
| AC-03 | 用户名不存在 | 登录失败，提示「用户名或密码错误」 |
| AC-04 | 密码错误 | 登录失败，提示「用户名或密码错误」 |
| AC-05 | 用户名或密码为空 | 登录失败，提示「用户名和密码不能为空」 |

**业务规则**

- BR-04：登录失败不区分「用户名不存在」和「密码错误」，统一提示。
- BR-05：JWT Token 有效期 24 小时。
- BR-06：Token 中携带用户 ID 和角色，供后续接口鉴权使用。

---

#### FR-AUTH-03 获取当前登录用户信息

| 属性 | 内容 |
|------|------|
| 优先级 | P1 |
| 触发者 | 已登录用户（含管理员和普通用户） |
| 前置条件 | 持有有效身份凭证 |

**描述**

已登录用户可查看自己的基本信息：用户名、邮箱、注册时间。

**验收标准**

| 编号 | 场景 | 预期 |
|------|------|------|
| AC-01 | 凭证有效 | 返回用户名、邮箱、注册时间 |
| AC-02 | 凭证无效或已过期 | 返回未登录状态，提示「请先登录」 |

### 3.2 文章管理

#### FR-ART-01 发布文章

| 属性 | 内容 |
|------|------|
| 优先级 | P0 |
| 触发者 | 管理员 |
| 前置条件 | 已登录且角色为 ADMIN；选择的分类存在 |

**描述**

管理员发布一篇新文章。文章可以立即发布，也可以保存为草稿。

**输入**

| 字段 | 规则 |
|------|------|
| 标题 | 必填；1-100 字符 |
| 正文 | 必填；纯文本，不限长度 |
| 分类 ID | 必填；须为系统中已存在的分类 |
| 状态 | 必填；`PUBLISHED`（发布）或 `DRAFT`（草稿） |

**验收标准**

| 编号 | 场景 | 预期 |
|------|------|------|
| AC-01 | 管理员填写合法，状态为 PUBLISHED | 发布成功，所有用户可见 |
| AC-02 | 管理员填写合法，状态为 DRAFT | 保存成功，仅管理员可见 |
| AC-03 | 标题为空或超 100 字符 | 失败，提示「标题为 1-100 字符」 |
| AC-04 | 正文为空 | 失败，提示「正文不能为空」 |
| AC-05 | 分类 ID 对应的分类不存在 | 失败，提示「分类不存在」 |
| AC-06 | 未登录 | 失败，提示「请先登录」 |
| AC-07 | 已登录但角色为 USER | 失败，提示「无权限」 |

---

#### FR-ART-02 编辑文章

| 属性 | 内容 |
|------|------|
| 优先级 | P0 |
| 触发者 | 管理员 |
| 前置条件 | 已登录且角色为 ADMIN；文章存在且未被删除 |

**描述**

管理员修改文章的标题、正文、分类或状态。至少修改一个字段。

**输入**

| 字段 | 规则 |
|------|------|
| 标题 | 可选；1-100 字符 |
| 正文 | 可选 |
| 分类 ID | 可选；须为系统中已存在的分类 |
| 状态 | 可选；`PUBLISHED` 或 `DRAFT` |

**验收标准**

| 编号 | 场景 | 预期 |
|------|------|------|
| AC-01 | 修改部分字段，字段均合法 | 修改成功，updated_at 刷新 |
| AC-02 | 将 PUBLISHED 改为 DRAFT | 文章从公开列表消失 |
| AC-03 | 将 DRAFT 改为 PUBLISHED | 文章出现在公开列表 |
| AC-04 | 文章已被删除 | 失败，提示「文章不存在」 |
| AC-05 | 未登录 | 失败，提示「请先登录」 |
| AC-06 | 已登录但角色为 USER | 失败，提示「无权限」 |
| AC-07 | 未修改任何字段（请求体为空） | 失败，提示「至少修改一个字段」 |

#### FR-ART-03 删除文章

| 属性 | 内容 |
|------|------|
| 优先级 | P0 |
| 触发者 | 管理员 |
| 前置条件 | 已登录且角色为 ADMIN；文章存在且未被删除 |

**描述**

管理员删除一篇文章。删除为逻辑删除——文章状态变更为 `DELETED`，不再出现在任何展示场景。

**验收标准**

|------|------|------|
| AC-01 | 管理员删除已发布文章 | 删除成功，文章从公开列表消失 |
| AC-02 | 管理员删除草稿 | 删除成功 |
| AC-03 | 文章已被删除（重复删除） | 失败，提示「文章不存在」 |
| AC-04 | 未登录 | 失败，提示「请先登录」 |
| AC-05 | 已登录但角色为 USER | 失败，提示「无权限」 |

#### FR-ART-04 获取文章详情

| 属性 | 内容 |
|------|------|
| 优先级 | P0 |
| 触发者 | 任意用户（管理员 / 已登录用户 / 未登录访客） |
| 前置条件 | 文章存在且状态为 PUBLISHED（非管理员视角） |

**描述**

根据文章 ID 获取文章完整内容。

**视角规则：**

| 请求者 | 可见范围 |
|--------|----------|
| 管理员（ROLE_ADMIN） | 所有文章（含 DRAFT），不含 DELETED |
| 已登录用户（ROLE_USER） | 仅 PUBLISHED |
| 未登录访客 | 仅 PUBLISHED |

**返回内容**

| 字段 | 说明 |
|------|------|
| 文章 ID | — |
| 标题 | — |
| 正文全文 | — |
| 状态 | PUBLISHED / DRAFT |
| 分类名称 | — |
| 作者用户名 | — |
| 发布时间 | — |
| 最后更新时间 | — |

**验收标准**

| 编号 | 场景 | 预期 |
|------|------|------|
| AC-01 | 任意用户请求已发布文章 | 返回文章完整信息 |
| AC-02 | 未登录访客请求草稿 | 返回「文章不存在」 |
| AC-03 | 已登录用户（ROLE_USER）请求草稿 | 返回「文章不存在」 |
| AC-04 | 管理员请求草稿 | 返回文章完整信息 |
| AC-05 | 请求不存在的文章 ID | 返回「文章不存在」 |
| AC-06 | 请求已删除文章 | 返回「文章不存在」 |

#### FR-ART-05 文章列表（分页）

| 属性 | 内容 |
|------|------|
| 优先级 | P0 |
| 触发者 | 任意用户 |
| 前置条件 | 无 |

**描述**

分页获取文章列表，按发布时间倒序。每篇文章返回摘要信息（不含正文全文）。

**视角规则：**

| 请求者 | 可见范围 |
|--------|----------|
| 管理员 | 可指定状态筛选（PUBLISHED / DRAFT / ALL），默认 ALL |
| 已登录用户（ROLE_USER） | 仅 PUBLISHED |
| 未登录访客 | 仅 PUBLISHED |

**列表项内容：** 文章 ID、标题、正文摘要（前 200 字符）、分类名称、状态、作者用户名、发布时间。

**请求参数**

| 参数 | 默认值 | 说明 |
|------|--------|------|
| page | 1 | 页码，从 1 开始 |
| size | 10 | 每页条数，最大 50 |
| categoryId | 无（全部） | 按分类筛选 |
| status | 见视角规则 | 仅管理员可指定 |

**返回信息**

| 字段 | 说明 |
|------|------|
| total | 总文章数 |
| page | 当前页码 |
| size | 每页条数 |
| pages | 总页数 |
| list | 当前页文章列表 |

**验收标准**

| 编号 | 场景 | 预期 |
|------|------|------|
| AC-01 | 访客请求，无参数 | 返回前 10 篇 PUBLISHED 文章 |
| AC-02 | size 设为 50 | 返回最多 50 篇 |
| AC-03 | size 超过 50 | 按 50 处理 |
| AC-04 | 传入 categoryId | 仅返回该分类下的 PUBLISHED 文章 |
| AC-05 | 页码超出总页数 | 返回空列表，total 仍正确 |
| AC-06 | 管理员指定 status=DRAFT | 仅返回草稿文章 |
| AC-07 | 普通用户指定 status=DRAFT | 参数被忽略，仍返回 PUBLISHED |
| AC-08 | 已删除文章永不出现在列表中 | — |
### 3.3 分类管理

#### FR-CAT-02 查看全部分类

| 属性 | 内容 |
|------|------|
| 优先级 | P0 |
| 触发者 | 任意用户（含未登录访客、已登录用户、管理员） |
| 前置条件 | 无 |

| 编号 | 场景 | 预期 |

- BR-07：文章数仅统计 PUBLISHED 状态的文章，DRAFT 和 DELETED 不计入。

## 8. 与 V1.0 差异摘要

| 变更项 | V1.0 | V2.0/V2.1 |
|--------|------|------|
| 角色 | 管理员 + 未登录访客 | 管理员 + 已登录用户 + 未登录访客 |

| 登录 | 仅管理员 | 管理员和普通用户共用同一接口 |
| USER 权限 | 不存在 | 本期等同于未登录访客；后续扩展点赞、评论 |
| 用户信息 | 无 | 新增获取当前用户信息接口（P1） |
